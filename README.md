# Python Programming MOOC 2026

My solutions to the exercises of the [Python Programming MOOC 2026](https://programming-26.mooc.fi/),
a free online course by the Department of Computer Science, University of Helsinki.

The course is split into two tracks:

| Track | Parts | Credits |
| --- | --- | --- |
| Introduction to Programming (BSCS1001) | 1–7 | 5 ECTS |
| Advanced Course in Programming (BSCS1002) | 8–14 | 5 ECTS |

I'm working through both, from the basics up to object-oriented and functional
programming. This repository is my learning log — the code here is written to
solve course exercises, not to be production-grade.

## Structure

```
python-programming-mooc-2026/
├── part-01/
│   ├── 01_emoticon.py
│   ├── 02_seven_brothers.py
│   └── ...
├── part-02/
├── ...
└── part-14/
```

One folder per course part, one file per exercise. File names follow the
exercise numbers and titles used in the course material, so a solution is easy
to trace back to its assignment.

## Running the code

Everything is plain Python 3 with no external dependencies, except where a part
of the course introduces one (`pygame` in the later parts, `unittest` for
testing).

```bash
git clone https://github.com/<Svetajism>/python-programming-mooc-2026.git
cd python-programming-mooc-2026/part-01
python3 01_hello_world.py
```
